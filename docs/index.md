# FaujiDhara

Faujiyon (veterans) aur kisanon ke liye kheti ki jaankari ka Android app.

- **Fasal Calendar:** Rabi, Kharif aur Zaid; 28 rajya aur 8 kendra shasit pradesh ki sabzi, phal, phool aur masale
- **3D paudha, asli naap:** oonchai, failaav, jad ki gehrai aur jad ka failaav, feet mein
- **Bina internet:** poora app offline chalta hai
- **Privacy:** version 1.0 koi personal jaankari nahi leta
