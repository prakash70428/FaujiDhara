# Changelog

Every release that goes to the Play Store gets an entry here.
Format: [Keep a Changelog](https://keepachangelog.com/), versions: [SemVer](https://semver.org/).

- **MAJOR** (2.0.0): big change that breaks something users relied on
- **MINOR** (1.1.0): new feature (login, feed, listings)
- **PATCH** (1.0.1): bug fix only

The Android `versionCode` (build number) is managed by EAS and goes up by itself on every
production build; only `version` in `app.json` is changed by hand.

## [1.0.0] - first closed test

### Added

- Fasal Calendar: Rabi / Kharif / Zaid guide, 28 states and 8 UTs with vegetables, fruits,
  flowers and spices
- Plant detail page: sowing months, care facts, companion plants, expert tip
- 3D plant card drawn to real scale (feet): height, spread, root depth and root spread,
  soil X-ray, 5.5 ft human for scale, growth stages, works on phone, tablet and laptop
- Works fully offline, collects no personal data
